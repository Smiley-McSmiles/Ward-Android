(`../LICENSE` and `MIT.txt`), but the APK links GPL-3.0-only encryption
libraries, so the APK as a whole is distributed under **GPL-3.0-only**.

| File | Applies to |
| --- | --- |

| `GPL-3.0-only.txt` | The combined APK; dino/libomemo-java, signal-protocol-java and curve25519-java |
| `GPL-2.0-or-later.txt` | Bundled freedesktop.org call sounds |
| `Apache-2.0.txt` | Smack, AndroidX, Kotlin, WebRTC, ZXing, Gson and other Apache-2.0 dependencies |
